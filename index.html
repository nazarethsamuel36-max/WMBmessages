📋 How to Use

  1. Open the Controller - Browse and select sermon messages
  2. Open the Presentation - This is your OBS browser source overlay
  3. In OBS - Add a Browser Source with the Presentation URL
  4. Control slides - Use the Controller to send slides to the Presentation view
  5. Copy URLs - Use the copy buttons to share links with others
